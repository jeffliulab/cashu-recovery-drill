# Cashu Recovery Drill

[Play the recovery drill](https://jeffliulab.github.io/cashu-recovery-drill/)

Open `index.html` in a browser. Three short exercises show what a Cashu wallet can reconstruct after device loss. Restore signatures from a fictional mint, inspect the state of the proofs, then decide which value the evidence supports. The exercise runs locally with no install or network connection. On GitHub, choose **Code → Download ZIP**, extract it, and open `index.html` with its three adjacent assets.

The first exercise distinguishes issued, unspent, pending and spent outputs. The second checks a retired keyset alongside its replacement. The third traces an incoming bearer token whose secret was never generated by the recipient’s wallet. Each answer explains what the wallet operator can conclude.

The records and states are fixed teaching examples. The page uses no real keys, tokens, balances, mint endpoints or cryptography. The table abbreviates candidate labels and the intermediate unblinding step. Its face values assume plain sat proofs and exclude fees. A live recovery also depends on the correct mint, keysets, compatible derivation and available records. The exercise does not predict whether a real wallet can restore a particular balance.

Run the model tests with `node --test test-engine.cjs` (Node.js 18 or newer). The browser version has no dependencies. Original code, examples and writing are provided under the MIT license.
