A wallet needs a matching signature and a spendable proof state. It must also search the right keysets. A seed can only reproduce material the wallet derived from it.

How this maps to Cashu

A mint signs ecash. A keyset identifies one set of its issuance keys. In a compatible wallet, NUT-13 derives candidates for each keyset from the wallet’s seed and a counter. NUT-09 returns matching blind signatures. The wallet reconstructs the proofs and uses NUT-07 to check their state.

The examples assume ordinary sat proofs and a reachable, cooperating mint. Values shown are face values before any swap or payment fees. Real recovery includes cryptographic validation, the correct mint and derivation scheme, and a wider counter search. The drill performs none of those live operations.
